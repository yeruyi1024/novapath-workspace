## 2. 所有改动按模块说明

### 2.1 品牌、应用身份与兼容

- 中文保留“星途”，英文统一为 **NovaPath**。`src/shared/product/product.json` 统一产品名称、功能开关与服务地址，应用 Logo、图标、托盘、窗口、启动/恢复页和安装包显示名同步更新。
- 保留 `com.starpath.desktop`、历史存储名称、数据库字段、IPC、协议及旧数据兼容标识。用户数据目录和旧数据库回退按迁移策略处理，避免改名丢失历史；不对持久化标识机械替换。
- 旧账户、营销、遥测、自动更新等服务默认关闭或地址为空。**本地后续版本仅配置公开技能与 MCP 目录两个白名单地址**，不自动安装或升级其中的扩展。
- 保留开源许可证、上游归属和第三方声明；公司 README 不变。独立编写文档辅助材料不代表整个应用及依赖为自研。

主要入口：`src/shared/product/`、`build/icons/`、`resources/`、`scripts/electron-builder-config.cjs`、`package.json`。

### 2.2 项目、对话与工作空间

- 新侧栏统一项目及对话，支持关联目录、改名、修改目录、搜索、置顶、移动归组及无项目对话；移除项目保留对话和文件，移动对话保留工作目录。
- 首页办公入口提供 Word、Excel、PPT、PDF 示例，不覆盖草稿、不自动发送；首页重复项目卡片移除，项目仍从侧栏及输入区选择。
- 未发送草稿持久化，重启后恢复。账户和设置收拢至侧栏底部，个人资料位于设置，订阅使用独立弹窗。
- 本地后续版本增加分组对话的展开/收起与当前会话可见性，统一首页、文件按钮、示例面板、登录及主题视觉；新安装默认浅色，已有外观偏好保留。
- 模型选择增加来源标记和说明；模型能力、权限和倍率仍由现有平台字段提供，不硬编码性能或收费结论。

主要入口：`Sidebar.tsx`、`components/projects/`、`services/workspaceProjects.ts`、`promptDraftPersistence.ts`、`components/quick-actions/`、`ModelSelector.tsx`。

### 2.3 公司登录、模型网关、余额与订阅

- 新增客户端公司认证适配器：密码、短信和两步验证，启动恢复并校验会话，支持刷新、失效、退出、窗口激活/网络恢复复查。
- 主进程保存和刷新凭据；Refresh Cookie 由系统安全存储加密，JWT 留在主进程内存，对 renderer 仅提供账户投影。隔离账户切换与迟到响应，失败不覆盖最近有效快照。
- 模型连接固定公司网关，API Key 验证成功后发现可用模型，失败保留原设置；替换旧厂商配置及登录入口。
- 只读读取账户、余额/累计用量/请求数与展示参数，按平台口径换算。**PR 当前界面隐藏额度；本地后续界面恢复余额及累计用量展示**，加载、陈旧数据和失败状态可见；未把原始 quota 直接命名为积分。
- 只读接入 `/api/subscription/plans`、`/api/subscription/self`。目前展示套餐标题、价格、币种、周期、订阅状态和有效期；额度及扣费偏好类型保留，不代表全部字段已开放展示。
- 短信提供发送中、脱敏号码、服务器等待时间、绝对截止倒计时和过期提示；换号/切换平台后旧 challenge 失效。本地后续登录成功提示并关闭窗口，失败统一为一个可访问的弹窗，避免重复报错。

**未实现：**原生购买、支付、订单、钱包充值和精确用量账单闭环。登录账户与模型 API Key 当前独立，仍须确认归属和实际扣费账户；页面余额不能直接作为任意 Key 可消费额度。套餐定价及积分展示研究是讨论稿，未写入平台、未发生真实交易。

主要入口：`src/main/libs/maasAuth.ts`、`src/shared/auth/maas*.ts`、preload/类型桥接、`services/maasSession.ts`、`maasSubscriptions.ts`、`starpathPlatform.ts`、`components/login/`。
