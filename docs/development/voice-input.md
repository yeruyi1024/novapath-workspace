# 本地语音输入

语音输入用于代替输入框打字：用户开始说话，结束后文字追加到当前草稿，再由用户发送。不保存录音文件，也不是与 AI 连续语音通话。目前识别结果在说完后返回，不宣称已经支持边说边出字。

## 用户流程与体积

- 安装包只包含识别引擎及许可证，不带模型。macOS arm64 当前未压缩资源共 8,029,765 字节，约 8 MB；此数字不是签名安装包的实际增量，其他系统须分别测量。
- 首次点击麦克风时说明需要下载约 190 MB（181.3 MiB）的语音包。用户点击“下载语音包”后才联网下载，不在安装或启动时自动下载。
- 下载显示实际已接收字节的进度，可取消；失败清理本次临时文件并允许重试。长度和 SHA-256 必须匹配后才原子安装，不用损坏文件覆盖既有模型。
- 模型存入 `app.getPath('userData')/asr/whisper-small-q5_1.bin`，后续无需重复下载。识别不依赖网关、密钥、Python 或用户自行选模型；不用语音的用户无需下载。
- 资源就绪后点击输入框的麦克风直接开始说话，不显示说明或就绪弹窗。再次点击停止图标结束并转文字；旁边的小状态条显示聆听/计时、转写及取消，Escape 可取消。系统首次麦克风权限仍需用户同意，最长 60 秒。
- 首次缺少语音包、下载进度和失败信息显示在输入区的小提示中。下载完成后提示收起，不自行启动麦克风；下一次点击图标直接说话。识别结束或取消后释放麦克风和本地子进程，模型不会持续驻留后台。

## 实现与维护

主进程使用 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) v1.9.5 与多语言 Whisper small Q5_1。固定的官方来源、版本、190,085,487 字节长度与校验值放在 `src/shared/asr/local-runtime.json`，构建及客户端下载共用此清单。音频为 PCM16、16kHz、单声道 WAV，经 stdin 管道传给识别进程，不开放 HTTP 端口、不上传、不写录音或转写文件。

每个应用最多同时启动一个识别任务，最长识别等待 120 秒。IPC 只接受主窗口主 frame，校验请求 ID 与音频；按窗口和请求取消，迟到结果丢弃，进程环境不传平台密钥，错误和 stderr 不回显音频、路径或诊断内容。已有草稿保留，结果不自动发送。

模型下载只访问清单指定的固定 HTTPS 地址，15 分钟绝对超时，不发送 API Key 或浏览器凭据。当前为官方 Hugging Face 地址；面向国内正式发行前须实测下载可达性。公司若提供稳定 CDN，应在同一清单替换来源并保持校验一致，不从用户输入的任意 URL 下载执行文件。

开发者通过 `npm run setup:local-asr -- --engine-only` 准备本机引擎；需要离线测试模型时运行 `npm run setup:local-asr`。构建机需要 CMake 与原生 C++ 编译工具链，用户不需要。可用 `STARPATH_CMAKE` 指向构建工具。打包 hook 强制 `includeModel: false`，且资源过滤排除 `model.bin`；每个目标需在对应系统构建，或准备已验证的目标资源。macOS 可通过 Apple SDK 构建另一架构，但编译不能替代真机运行。

引擎、模型与 miniaudio 的真实许可保存在语音资源 `licenses/` 并随包发布；不宣称底层模型或引擎为星途原创。升级要同步版本、校验值、许可、真实中文准确率、目标系统兼容性和取消/超时验证，不能只替换二进制。

## 平台能力与验收边界

原平台转写 IPC 保留为后续接入边界，普通麦克风入口已改用本地识别；不会在失败后静默上传音频。网关未开放转写模型不会阻止本地识别。本轮未部署服务器、修改套餐或计费。

真实引擎可识别自生成中文短句，并验证空音频、取消及重试。这不是人声、方言或噪声准确率证明；已有一条合成音频存在错字，识别质量须在人声场景继续验收。真实麦克风、长短句、噪声、权限及 Windows / Linux 原生安装仍待验收，不能把单元测试或 macOS 编译写成全平台通过。
