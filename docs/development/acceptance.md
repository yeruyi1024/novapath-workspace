# 开发与发行验收

记录实际执行命令、结果、系统和未验证范围。以下是按改动选用的门槛，不是每次修改都运行所有发行流程。

| 改动 | 必须验证 |
| --- | --- |
| 仅文档 | 链接、规范冲突、`git diff --check`；无需代码测试 |
| TS/TSX | 改动文件 ESLint：`npx eslint --ext ts,tsx --report-unused-disable-directives --max-warnings 0 <files>`；相关测试 |
| Renderer / UI | `npm run build`；相关测试；实际客户端交互与截图 |
| Main / preload / IPC | `npm run compile:electron`；相关测试；权限、错误和监听清理 |
| 数据 / 凭据 | 旧数据迁移、保存失败、重启恢复及敏感信息泄漏检查 |
| OpenClaw / 插件 | 启动、配置同步、真实对话、启用/关闭、升级失败与回退；必要时重建固定运行时 |
| CI / 打包脚本 | `node --test scripts/ci-tests/*.test.cjs`；对应输出和安装契约检查 |
| 阶段交付 / 合并前代码集成 | Renderer 构建、Electron 编译、完整 `npm test`、改动文件 lint；GitHub CI 单独记录 |

完整测试出现偶发失败须保留首次结果、定位并复跑相关项；明确最终复跑范围，不能把单项通过写成全库通过。跳过项和未执行检查都须注明。现有全库 lint 债务不应扩大，但不能用它豁免新改动的 lint。

## 核心体验验收

- [ ] 项目目录绑定、新建/切换项目、无项目对话、搜索、重命名、移动和删除正常。
- [ ] 真实网关回复、流式输出、停止、错误与重试正常，不重复生成或泄露凭据。
- [ ] 回复中的相对/绝对路径正确解析；文档、表格、PPT 和图片在右侧展示，越界路径和损坏文件有反馈。
- [ ] 重启后历史、项目、草稿与必要配置保留；无旧品牌服务被意外启用。
- [ ] 浅色/深色、窄窗口、侧栏收起、预览开启和键盘操作通过。
- [ ] 远程连接和所改插件实际可用；只展示已确定的入口。

按改动范围勾选，未测项保持未勾选。一次界面截图不能代表上述功能验收。

## 发行门槛

分别记录 macOS、Windows、Linux 的系统版本、架构、包版本和证据；不能以 macOS 测试推断其他系统通过。

- [ ] 干净系统安装、首次启动和随包运行时就绪。
- [ ] 网关对话、文件生成与预览、路径含空格及中文。
- [ ] 升级保留数据、凭据存储边界、卸载行为与回退。
- [ ] 安装包签名、更新来源、失败提示与品牌资源。
- [ ] 公司登录、套餐、额度协议以及开源许可证要求核对。

发行负责人根据真实证据确认可发布；未满足时只标记为演示或内测，不宣称正式售卖完成。

## PR 完成条件

沿用公司 `.github/PULL_REQUEST_TEMPLATE.md`；中文说明覆盖其各项。UI 截图脱敏后直接上传附件并验证能显示。说明 Electron 与数据影响、实际测试和未完成平台验收。保留公司 README；不要把创建 PR、无冲突或本地通过写成已合并或 CI 通过。
