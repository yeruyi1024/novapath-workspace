# 星途界面规范

## 已确定的基调

以用户确认的白色主界面为基准：中性色正文、浅灰侧栏、少量蓝紫品牌点缀。深色与跟随系统同等支持，外观只提供这三个选项。品牌 Logo 使用当前星途资源，禁止恢复龙虾形象、旧启动动画或大面积装饰渐变。

品牌色用于 Logo、选中、焦点和主要操作；不把普通正文、所有边框和整块背景染色。优先使用现有主题 token 和组件，避免新建平行配色体系。新增图标沿用现有线性图标的尺寸和笔画，不能用表情或混杂风格代替功能图标。

## 信息和布局

侧栏以新对话、搜索、项目和历史对话为主；支持项目内和无项目对话。历史以紧凑单行标题为主，运行和异常可见，次要时间和操作按需展示。正文有稳定阅读宽度，窄窗口可换行，不靠扩大最小窗口掩盖溢出。

输入区集中附件、工具、项目和模型选择；不在右上角重复展示模型设置入口。文件成果通过现有文件卡片和标签在右侧预览，不恢复独立文件预览导航。根据 2026-10-12 恢复官方回答链路的决定，正文 Markdown 链接沿用官方系统打开行为，不再次添加预览拦截。预览打开时输入区和正文仍须可用，长路径、长模型名和表格不能挤坏布局。

设置沿用当前简洁布局；远程连接只有四个渠道，配置状态、错误和下一步操作清楚。不要恢复实验功能、对话配置导航或高级上游模型编辑页。正常使用文案说项目、对话、工具和任务，不强调内部 agent 或调度机制。

梦境设置及其快捷键继续清退，普通记忆保留，旧梦境自动整理关闭。按 2026-10-13 用户要求恢复邮箱设置，归入连接与维护，用于多账号配置和连接测试；复用已有邮件技能与凭据，不恢复其他退役功能。公司套餐本阶段只读展示，不显示购买入口。

设置分类按“工作空间、平台与工具、连接与维护”直接分组，不再藏在高级设置折叠层中。页头与保存/取消固定，正文独立滚动；限制正文宽度，避免长说明铺满窗口。800px 窄窗口采用顶部横向导航，可滚动查看全部分类；方向键移动导航焦点，回车选择。分组、输入框、按钮和状态沿用 `components/settings/settings.css`，记忆页不重复嵌套大卡片，空状态、搜索无结果、加载分别提供真实反馈。

## 回答与加载

回答正文、引用、表格、代码和文件卡片复用同一渲染链路。引用用轻底色和清楚留白；表格表头与分隔适度突出，宽表格可横向滚动，保留对齐和文本选择。链接有明确交互，不能通过样式掩盖真实 URL 或修改模型回答。

回答规范优先说明结果、依据与未完成项；不把提示词当成模型质量保证，也不改写既有历史。运行细节按需展开。

启动只展示真实状态、轻量加载动效和可处理的错误；禁止估算百分比冒充完成进度或人为拖延进入首页。支持系统减少动画偏好。开发验证避免频繁刷新用户正在使用的窗口。

## 每次 UI 改动必查

- 浅色、深色、键盘焦点、图标按钮可访问名称和减少动画。
- 空状态、加载、失败、长中文/英文文本和窄窗口。
- 项目/无项目、新对话/历史对话、草稿、滚动位置及右侧预览。
- 不泄露凭据的实际截图；说明截图版本、系统及未验证范围。

不得用“参考 Codex”代替验收条件；PR 应描述具体布局和交互变化。
