# 星途设置工作台视觉重构

状态：展示重构与 macOS 隔离组件验收完成；Windows/Linux 与 GitHub CI 待验收。

## 问题与范围

用户认为当前设置的侧栏与表单形态仍过于接近上游，要求重新设计。采用顶部三组分类导航、独立页头、分栏表单和统一操作区；外观选择用主题符号和抽象文字示意，模型页突出密钥输入。沿用白灰主题和适量紫色，保留开源许可及署名，不将视觉差异当作授权保证。

仅改设置展示组件、样式与双语文案；大 Settings 文件只调整展示壳及操作区，不迁移其业务状态。保存/取消、插件离开确认、快捷键、记忆、企业隐藏配置和错误反馈继续使用现有逻辑。不改 gateway、回答链路、插件/技能/MCP 加载执行、数据库或用户数据。

## 验收

- 所有当前分类仍可到达；顶部组不展示被企业隐藏的空分类。方向键、Home/End、回车和可见焦点可用。
- 页面正文独立滚动，关闭与保存操作始终可见；800px 和 600px 窗口以及长英文不产生横向页面溢出。
- 浅色/深色、三种主题、密钥显示切换、记忆操作和错误/加载状态可用。无新增网关地址、注册、梦境或邮箱入口。
- 改动 TS/TSX ESLint、生产构建、相关设置/配置测试及隔离 Electron 交互与脱敏截图。用户当前客户端不重启，Windows/Linux 与 GitHub CI 分别记录。
