# 隐藏文件分享及旧发布权益入口

状态：客户端文件分享与旧发布权益入口隐藏、本地验证完成；活动旧包未替换，原生交互和跨系统验收待完成。

## 问题与范围

用户在示例文档预览中点击“分享”后进入旧订阅登录弹窗，要求删除分享。文件分享入口分布在对话文件卡片、右侧预览工具栏、浏览器 HTML 预览工具栏、文件库列表和文件预览。客户端统一隐藏新建文件分享入口，避免从其他位置再次触发该弹窗。

保留现有分享记录的查看、停止和删除能力，以免既有外部链接失去管理入口。保留分享持久化、IPC 与兼容协议，不修改 gateway 平台；本地文件打开、复制、预览、已有网站管理和对话收发保持原有行为。

用户进一步要求旧品牌业务逻辑不再展示。排查发现本地网站部署的新建按钮、历史分享/网站的“订阅恢复”按钮，以及发布额度、体验和订阅弹窗仍可展示旧商业权益。补充隐藏旧网站部署创建入口与旧付费恢复按钮；若保留的管理操作触发旧发布限制，仅显示中性不可用提示，不展示旧订阅、购买或体验额度引导。已有分享/网站的停止、删除和查看继续可用。模型与媒体的旧订阅入口目前受关闭的旧账户总开关控制，本轮不动对话输入输出或媒体执行逻辑。

## 验收与验证

- 文档等文件在对话卡片、右侧预览、HTML 浏览器预览和文件库中均不再显示新建“分享”操作。
- 已有分享记录仍能进入管理页；文件打开、复制和预览可用，本地服务预览与已有网站管理不受影响。
- 旧网站部署创建按钮和订阅恢复/购买引导不再展示；已存在的网站与分享仍可管理。遗留错误路径只给中性不可用提示。
- 运行入口策略相关测试、改动 TS/TSX 严格 ESLint、隔离 renderer 构建与 `git diff --check`。不重启用户活动客户端；原生新包、真实账号和 Windows/Linux 单独验收。
