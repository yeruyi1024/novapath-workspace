# 恢复邮箱与公司套餐查询

状态：实现、本地自动验证及 macOS 隔离 Electron 验收完成；真实邮箱、真实平台账号和 Windows/Linux 待专项验收。

## 范围

用户要求恢复邮箱，并先接公司套餐接口，购买后续补充。恢复设置邮箱多账号页及前端服务；沿用既有邮件 IPC、存储、技能和连接测试，读取失败不得降级为空配置覆盖用户账号。梦境仍关闭，不恢复邮箱快捷键。

套餐通过当前公司主进程账户会话只读请求 `/api/subscription/plans` 和 `/api/subscription/self`。只投影展示字段，JWT 不进入 renderer；校验账户归属，保留上次成功结果，退出/换账号清理。账户弹窗展示套餐、有效期、额度、扣费偏好与同步状态。购买、支付、修改偏好、模型密钥绑定不在本轮范围。gateway 严格只读。

## 验收

- 邮箱旧账号加载、新增/编辑/默认/启停/删除、读取失败保护及连接检查。
- 套餐空态、活跃/过期/取消、无限额度、失效/断网、旧响应隔离，接口权限与凭据边界。
- 深浅色、窄窗、键盘；相关测试、改动文件 lint、完整测试和隔离构建。
- 不重启用户客户端，不重建活动运行时，不改回答核心、公司 README，不提交推送。

## 最终实现

- 设置恢复邮箱分类，归入连接与维护，恢复独立绘制的邮箱图标、多账号表单、默认账号选择、连接测试与前端服务。旧邮箱快捷键不恢复，梦境继续关闭。
- 加载失败抛出真实错误，页面仅显示重试，禁止新增账号覆盖读取失败的旧配置。保存沿用既有账号存储与串行队列；补充输入控件可访问名称。
- 新增 `maas:subscriptions` 主进程只读 IPC，固定访问公司 `/api/subscription/plans` 与 `/api/subscription/self`。先加密恢复/刷新登录凭据，GET 使用仅存在主进程内存中的 JWT；401 刷新重试，核对用户 ID。对 renderer 仅提供套餐标题、价格、周期、额度和订阅投影，不暴露支付产品 ID 或凭据。
- 当前星途账户面板展示套餐与订阅：有效期、已用/总额度、剩余额度、下次重置、有效/到期/取消、平台扣费偏好、可用套餐和同步时间。零总额度按平台语义显示不限额度，平台金额配置缺失时明确显示原始额度。
- 打开面板、激活窗口、恢复网络及手动操作刷新；合并同一轮查询。关闭/换账户隔离迟到结果，断网保留上次成功数据并标记。没有改写扣费偏好，不发送购买请求，也没有启用旧账户/营销开关。登录账号与模型 API Key 仍独立，页面明确提示所属账户边界。

## 后续电脑操作调整（2026-10-13）
