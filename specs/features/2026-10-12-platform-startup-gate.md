# 平台登录启动门禁与固定模型网关

状态：实现与 macOS 本地验证完成；真实账号登录/SMS、Windows/Linux 原生验收和 GitHub CI 待完成。

## 问题与范围

欢迎页可绕过登录，历史配置仍可能把模型请求发往其他网关。启动必须先恢复并校验公司平台会话，校验通过才挂载工作空间。保持用户确认的欢迎页布局，移除“稍后登录”、配置网关及注册入口。模型设置只显示密钥，地址固定为 `https://gateway.ai.shilijia.xyz/v1`，密钥保存时自动发现模型。

范围包含平台账户状态服务、启动页面、设置保存、主进程配置约束及相关测试；保留历史项目、对话和旧供应商记录，旧连接禁用。已有公司平台密钥与模型继续使用。账户登录凭据与模型 API Key 独立，不把登录 JWT 当作模型密钥。

## 验收与验证

- 未登录、会话过期或确认失效：只显示登录页；密码/SMS/二次验证成功才进入。
- 重启：加密恢复刷新凭据并向平台校验；校验中不闪现工作空间。网络与安全存储失败可重试或重新登录。
- 登录后周期、窗口激活与网络恢复时检查会话；退出成功返回登录页。失败反馈真实，不伪装成功。
- 设置仅密钥输入；保存非空密钥时发现模型成功才更新配置；空密钥可清除连接。主进程启动与配置写入固定网关，禁用旧路由。
- 相关 Vitest、修改文件 ESLint、renderer 构建、Electron 编译；隔离 Electron 验证登录/恢复/失效/退出、键盘/窄屏/深浅色及密钥设置。真实账户和 Windows/Linux 原生验收单独记录。

## 最终实现与证据

- `PlatformSessionGate` 在工作空间与修复面板挂载前校验平台会话；独立状态服务提供 checking / signedOut / signedIn / error，校验失败不使用未经验证的缓存账户放行。请求合并、超时与旧响应保护均有测试。
- 欢迎页保留左右布局，只显示登录；Windows 标题栏独立保留。成功后初始化工作空间，没有密钥时自动打开密钥设置。后台每 5 分钟及窗口激活/网络恢复时复查；确认失效返回登录。
- 主进程仅接受固定平台登录 origin；加密凭据恢复也拒绝其他 origin。退出在平台断网时仍清除本机凭据并返回登录，页面明确提示服务器撤销未确认。
- 主进程启动及每次 app_config 写入、renderer 配置载入及保存均执行固定网关策略。保留并禁用旧连接，采用已有公司网关槽位；未配置时没有虚构默认模型或备用供应商。主平台模型路径固定为 `/v1`，受管供应商关闭 OAuth/其他路由覆盖。
- 设置只显示平台密钥。新增/修改密钥或在密钥页面保存时通过固定 `/v1/models` 验证并同步；失败不覆盖原配置，空值清除。模型在对话输入区选择。
- 本地：`npm run build`、`npm run compile:electron`、25 个改动 TS/TSX 文件 ESLint 与 `git diff --check` 通过。完整 `npm test`：547 个测试文件通过、16 个原有跳过；5,852 项通过、148 项原有跳过。首次全量发现一项旧 DeepSeek 默认地址断言，按固定公司网关的要求更新并补充禁用旧路由/空目录断言，最终全量复跑通过。
- 隔离 Electron 使用本地 fixture 服务、真实启动门禁/登录表单/密钥组件、真实 main IPC/HttpOnly Cookie/safeStorage：未登录不挂载工作空间、错误密码不放行、登录后进入、密钥失败不覆盖、密钥成功同步、清空内存 Cookie 后从加密文件恢复、401 失效回登录、再次登录、短暂断网保留已验证会话、通过账户按钮离线退出均通过。浅色/深色及 800px 窗口截图已检查，窄屏可纵向滚动且无横向溢出。
- 真实完整客户端已启动，并用电脑操作确认显示新版登录页且工作空间未挂载。未填写真实密码或发送线上短信；隔离 fixture 测试不代表真实账户验收。
