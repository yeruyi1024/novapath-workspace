# 设置顶部与首页留白优化

状态：实现完成，本地验证通过。

## 问题与范围

用户继续要求优化。900px 及以下窗口的设置导航将品牌、搜索、分类上下堆叠，占用较多正文高度；首页使用无上限的视口比例留白，长项目名称也需要明确换行规则。

本轮只改 renderer 布局：窄窗将品牌与搜索放在同一行，分类仍可横向滚动；620px 以下进一步收紧品牌、隐藏视觉分组标题，保留全部分类按钮和现有键盘导航。首页顶部留白限制在 32–88px，短窗口沿用 24px，超长标题允许断行，短窗口 Logo 略缩小。

不调整任何保存/取消、搜索、账户、订阅、项目选择、输入提交、对话渲染、插件/技能/MCP、主进程、数据库、凭据、运行时或只读 gateway。复用 SettingsNavigation 和当前主题 token。

## 验收

- 1200/800/480px 浅深色、中英文设置布局；窄窗搜索与关闭不重叠，所有分类、方向键/Home/End/Enter、搜索清除和草稿保留正常。
- 低高度窗口正文及保存操作可达；首页长中英文标题不溢出，留白受上限限制。
- 改动 TS lint、settingsEscape 定向测试、隔离生产构建、diff 检查；本地组件预览和活动 macOS Electron 热更新截图，不重启，不保存测试偏好，不提交推送。

## 结果

- 设置 800px 下品牌/搜索同排，分类仍保留分组标题；480px 使用单行分类。英文 480px 导航高度实测 128px，搜索右边缘 401px、关闭左边缘 413px，无重叠和页面横向溢出；800px 导航高度约 155px。
- 隔离预览浅深色、中英文通过；搜索无结果及清除后字号草稿 15 保持，End 自动滚动到 About，Enter 正常切页。800×560px 正文滚动区仍有约 205px，固定保存/取消均可见。
- 首页样式隔离预览 480×560px 验证无空格超长英文与中文标题自动换行且文档不横向溢出；短窗顶部 24px、Logo 40px；1200px 高窗口顶部上限 88px。
- Node 24.21.0：CoworkView 严格 ESLint、settingsEscape 3 用例、diff 检查及隔离 `npm run build`（含类型检查）通过。保留既有 Vite CJS、分包和 lottie 提示；没有重复全库业务测试。
- macOS 活动 Electron 设置关闭正常，首页热更新后留白已收紧，保留项目选择、模型与文件快捷操作，停留首页供查看。原生截图 `.work/ui-compact/desktop-home.png`；脱敏设置预览 `docs/pr-screenshots/2026-10-13/compact-settings-dark-480.png`。

范围内无待办；Windows/Linux、完整真实平台业务回归和 GitHub CI 未在本轮验证。未重启客户端，未保存用户测试偏好，未提交推送；只读 gateway 未改动。
