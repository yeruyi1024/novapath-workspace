# 星途平台余额同步与核对

状态：客户端实现与 macOS 本地验证完成；真实账户的新版本验收、Windows/Linux 和 GitHub CI 待完成。

## 问题与范围

平台钱包显示金额与请求数，星途账户弹窗仅显示登录响应中的原始额度。使用公司 new-api 的账户接口和展示配置，使两处数据口径一致。只读接入，不写余额、创建订单、发放积分或改变模型 Key。

## 行为和验收

- 主进程使用当前平台登录会话访问 `/api/user/self`，从 `/api/status` 获取 quota 单位、展示币种和展示汇率。JWT 仅保存在主进程内存，不进入 IPC、日志或持久化。
- 当前余额、累计用量和 API 请求数采用平台最新账户数据。USD、CNY、CUSTOM、TOKENS 均按平台配置展示；缺失或非法配置不自行猜测汇率。
- 账户弹窗提供同步时间及可展开原始额度/换算明细；失败保留上次成功数据并明确提示。打开、手动刷新、前台周期检查、恢复网络、对话完成/失败触发同步。
- 切换或退出账户丢弃前账户的账务数据；过期响应不能覆盖新会话。账务接口失败不阻断已经校验的登录。
- 截图示例：4,285,772 / 500,000 × 7 显示 ¥60，2,953,408 同比例显示 ¥41.35；请求数来自 request_count。

## 验证

相关 Vitest 覆盖换算、账户隔离、IPC 凭据边界、过期/断网和刷新竞态；改动文件 lint、renderer 构建、Electron 编译。隔离 Electron 使用真实 IPC 和本地 fixture 验证浅深色、窄窗口、同步变化/失败/退出与截图。不重启用户正在运行的客户端。真实账户与 Windows/Linux 验收单独记录。

## 最终实现与验证结果

- 新增 `maas:billing` 只读 IPC。每次先通过加密恢复的 HttpOnly Refresh Cookie 校验当前会话，再使用仅在主进程内存中的 JWT 获取 `/api/user/self` 和无凭据的 `/api/status`；账户 ID 校验通过后整体发布额度、用量、请求数与换算配置。刷新凭据或确认会话失效时保留/清理账务快照。
- 金额使用平台额度单位及展示汇率，不采用充值购买价格。线上公开 `/api/status` 已确认 CNY、500,000 quota/USD、展示汇率 7；按截图原始值换算分别为 ¥60、¥41.35。没有读取或修改线上真实账户余额。
- 账户弹窗显示三项统计、最近同步时间和可展开换算明细。加载显示占位/进度，失败保留上次成功数据并标记。登录后、打开弹窗、手动刷新、前台 5 分钟周期、窗口激活/网络恢复、对话完成/失败刷新；请求合并且旧响应不能恢复已经退出的账户或覆盖新账户。
- Node 24.21.0、macOS：4 个定向测试文件 54 项通过；12 个改动 TS/TSX 文件 lint、`npm run compile:electron`、`npm run build` 和 `git diff --check` 通过。完整 `npm test`：547 个文件通过、16 个原有跳过；5,860 项通过、148 项跳过。初次 lint 的 import 排序已修复并复验；构建保留仓库已有的包体积/动态导入提示。
- 原生隔离 Electron 使用真实 Cookie/safeStorage/main IPC 和本地契约服务：最新账户覆盖登录旧额度、平台展示比例变化、请求数更新、对话完成/失败与窗口激活刷新、断网保留上次值、非法比例提示、加密重启恢复、401 失效、切换账户、退出与凭据不进入 IPC 均通过。浅深色、440px 英文/中文无横向溢出、转换明细及真实 Tab/Shift+Tab 焦点循环通过。截图已人工检查。
