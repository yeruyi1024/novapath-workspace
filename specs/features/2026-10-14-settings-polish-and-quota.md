# 设置布局与账户额度展示

状态：客户端实现与本地验证完成；真实平台账单、原生客户端及 Windows/Linux 待专项验收。

## 问题与范围

设置页已有分组导航和统一样式，但窄窗口正文紧贴页头；账户页重复展示昵称，且已有平台账单快照未给用户提供简洁的可用额度信息。本轮继续打磨 renderer：收紧账户信息、补足窄窗留白，并在账户资料中展示平台返回的余额与累计用量。

额度只使用现有 `maas:billing` 快照及其平台展示换算规则。没有成功同步时显示加载或不可用；同步失败且有旧数据时明确标注旧数据。账户刷新同时更新账单，不新增计费推断或购买操作。

输入/输出、回答渲染、插件/技能/MCP 执行、主进程、IPC、凭据与 gateway 平台均不在修改范围。不重启用户活动客户端，不提交或推送。

## 验收与验证

- 设置页宽窄窗口正文与页头有稳定间距，导航、搜索、固定操作栏及焦点可用。
- 账户资料在浅深色与窄窗口可读；可用额度和累计用量遵从平台配置，不将原始 quota 擅自称为积分。加载、失败、旧数据和刷新有明确状态。
- 执行改动 TS/TSX 严格 ESLint、账单及会话相关测试、隔离生产构建、`git diff --check`，并进行可用的界面检查。真实平台账单与 Windows/Linux 真机验收单独记录。

## 结果

- 设置页在 900px 及以下补足页头与正文间距。账户资料去掉重复昵称，改用两项账户信息与一块余额卡片；360px 以下头像、姓名和刷新操作分行，避免姓名被压成竖排。余额卡片显示平台配置下的当前余额和累计用量，并注明模型扣费取决于密钥所属账户。
- 刷新账户时顺序更新资料和账单；成功账单仅用于同一账户，加载、失败和旧数据使用既有会话状态反馈。短英文标签使用双语文案，账户状态动画尊重系统减少动画偏好。快捷示例区原有硬编码中文改为双语文案。对话输入/输出及插件执行接口未改。
- Node 24.21.0、macOS：全量 `npm test` 为 557 个文件通过、16 个跳过，5,926 项通过、148 项跳过；改动 TS/TSX 严格 ESLint、`npx tsc --noEmit`、`git diff --check` 通过。隔离目录 `.work/ui-polish-20261014/build` 的最终 `npm run build` 通过，日志为 `build-final.log` 和 `tests.log`；未覆盖用户活动运行时。
- 隔离浏览器预览使用本地虚构账户与账单。1200px 浅色中文、480px 深色英文和 360px 深色英文检查了余额、信息层级、导航、搜索、正文滚动及固定操作栏；480px、360px 文档宽度不超过视口，360px 姓名换行问题修复。脱敏截图为 `.work/ui-polish-20261014/settings-account-light.png` 与 `settings-account-dark-480.png`。预览脚本与截图均在忽略目录，没有提交。
- 未使用真实平台账户或充值数据，浏览器组件预览不代替原生 Electron 与真实平台联调；Windows/Linux、GitHub CI、实际输入输出及插件端到端未在本轮重测。gateway 严格只读，没有提交或推送。
- 用户后续要求输入框略微下移：新对话首页标题下方间距由 `mt-8` 调为 `mt-12`（约 16px）；普通会话输入区的底部留白由 `pb-4` 调为 `pb-2`（约 8px）。输入框高度、附件/发送操作及输入输出协议均未改。两处 TSX 严格 ESLint、隔离 `npm run build`、构建 CSS utility 存在性检查和 `git diff --check` 通过；活动旧包没有重启，原生新包位置目测与窄窗口交互待验收。
