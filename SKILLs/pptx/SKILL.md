# 星途演示文稿

使用 `STARPATH_PYTHON` 的随包 Python 和 `python-pptx`。脚本目录由 `SKILLS_ROOT/pptx/scripts` 解析，不依赖系统 Python、浏览器下载或其他客户端的工具。

## 选择操作

新稿先确定用途、信息优先级和页面尺寸，再用 `Presentation` 创建文字、图片、图表和形状。图片必须有可用来源或由用户提供。参考稿先读取主题、页数和内容，编辑时沿用其设计；不把别人的作品改个标志当成原创。

- 内容清点：`slides.py inspect 输入.pptx` 输出各页文本、形状索引与演讲者备注。
- 文本修改：`slides.py replace 输入.pptx 输出.pptx --slide 0 --shape 2 --text "新标题"`。页与形状索引从 0 开始；该入口处理纯文本形状，保留第一个文本 run 的格式并重新读回核对。对含多种格式或超链接的段落，直接使用 `python-pptx` 对指定 run 定点修改。
- 排序或取出指定页：`slides.py reorder 输入.pptx 输出.pptx --order 2,0,1`。传入不重复的有效页索引，引用的媒体和备注关系随页保留；不会重新绘制原页面。
- 修改备注：用 `slide.notes_slide.notes_text_frame`，先确认备注布局存在；不要为了检查而创建空备注页。
- 需要 HTML 风格排版时，先把页面元素与坐标转成 PPT 形状，图像仅用于适合栅格化的区域。可用本机工具产生参考图，但最终文件的可编辑性要如实说明。

## 版面核对

每页只突出当前要表达的信息。正文、数字和图例保持可读；图表标明单位和数据来源；留出安全边距，检查形状是否超出画布。不要为凑页数重复内容。

中文稿先确认实际渲染环境有可用的中文字形，设置适用的字体与东亚字体属性；不要只设 Arial 就假定导出时会正常回退。导出 PDF 后既检查页面图像，也读取文本与原稿抽样对照。出现空白、方块或重复错字时，保留原稿并修正字体后生成新的检查文件；不能仅凭 PPTX 回读成功宣称 PDF 或其他软件打开正常。

保存后重读，检查页序、文字、备注、图片及页数。星途右侧提供 PPTX 预览；若本机已有 LibreOffice，可用其转换成 PDF 后逐页检查，未做渲染时说明限制。脚本默认不覆盖现有输出。

交付时说明已生成或修改什么、哪些检查完成，并给出 PPTX 文件路径引用。复杂动画、外部字体和应用间版式差异需要对应软件验证。

链接目标必须是验证存在的完整路径或任务目录内相对路径，不能写带省略号的缩略目录；简短文件名仅用于链接标签。
